# MOHAMI-DZ

This repo is a frontend for MOHAMI-DZ , a modern legal-services website built with React and Vite. It helps users discover lawyers, view profiles, compare options, and explore a clean, responsive experience for legal support.

## Features
- Lawyer directory and profile browsing
- Search and result pages
- Detailed legal service information
- Review and rating flow
- Responsive user-facing interface
- Separate lawyer dashboard experience

## Run locally

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build for production

```bash
npm run build
```

## Tech stack
- React
- Vite
- React Router
- CSS styling

## Project status
This project is a front-end showcase for a legal services platform and is ready to be customized further for production use.
